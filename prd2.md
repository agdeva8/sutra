If someone opens the MVP app, they should be able to see and do the following core actions:

* **Open Scratch Instantly:** Access a dedicated, persistent reflex-capture page or shell affordance in under three seconds to dump raw thoughts, voice transcripts, or photos without any categorization overhead.


* **Perform Frictionless Capture:** Type text into a single input field, attach files, or take photos via the mobile browser camera (`capture="environment"`) with guaranteed sub-300ms acknowledgment.


* **View the Two-Pane Split Feed:**
* See unprocessed, pending, or failing thoughts in the top pane (e.g., items showing `reading...` or asking a single inline clarifying question like `couldn't tell which goal`).


* See successfully processed, handled items in the bottom pane paired directly with their original input provenance (what was said or uploaded).




* **Manage Automated Plan Actions Safely:** View auto-applied undated tasks, timetable blocks, or blockers in the schedule, and use a one-tap `[ undo ]` or `[ revert ]` button to safely roll back any automated change.


* **Trace Artifact Origins:** Tap on any generated plan item or task to instantly view its origin line and trace it back to the exact sentence or photo it came from.
